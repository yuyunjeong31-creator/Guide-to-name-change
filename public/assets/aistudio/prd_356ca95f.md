# PRD: 계약정보 변경 모바일 길잡이

> 과제명: 바뀐 내 정보, SH에도 알려주세요!
> 구현 환경: Google AI Studio (Build) 단독, 공유 링크로 심사
> 문서 상태: 최종 보완본 + 큰글씨 모드(돋보기) 반영 (미확인 항목은 7장에 정리)

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | 바뀐 내 정보, SH에도 알려주세요! - 계약정보 변경 모바일 길잡이 |
| 이용 대상 | 개명·주민등록번호 변경이 생긴 SH 임대주택 계약자, 사망·혼인·이혼으로 명의변경 상담이 필요한 입주민과 가족 |
| 형태 | 모바일 우선 단일 화면 웹앱 (React), 아코디언 방식 |
| 핵심 가치 | 사유를 고르면 필요한 구비서류와 담당 센터 연락처를 한 화면에서 확인 |

### 챌린지 공통 조건
- 비개발자 4인, 실습 3시간, Google AI Studio(Build)만 사용
- 결과물에 DB 등 외부 프로그램 사용 불가 (계획 단계의 DB 언급은 무방)
- GitHub-Vercel 없이 AI Studio 앱 공유 링크로 심사
- SH 청렴 캐릭터 사용 가능

## 2. 목표와 비목표

**목표**
- 5개 사유(개명, 주민등록번호 변경, 사망, 혼인, 이혼)별 구비서류를 쉽게 확인
- 사망·이혼·혼인은 관할 주거안심종합센터 연락처와 지도로 연결
- 고령자와 가족도 쓸 수 있는 큰 글씨, 키보드 지원, 쉬운 말
- 돋보기 버튼 하나로 전체 글자를 키우는 큰글씨 모드 제공

**비목표 (만들지 않음)**
- 로그인, DB, 외부 API, 서버 저장
- 이름, 주민번호, 계약번호 등 개인정보 입력란
- 온라인 접수·상담 신청 폼
- 서류 양식 파일의 앱 내 첨부

## 3. 화면 구조 (단일 화면 아코디언)

화면 이동 없이 한 화면으로 구성한다. '처음으로', '다른 상황 보기' 버튼은 만들지 않는다.

1. **상단 영역**: 오른쪽 위 고정 돋보기(큰글씨) 버튼, 제목, 부제('해당하는 상황을 눌러 구비서류를 확인하세요'), 안내 문구, SH 청렴 캐릭터(이 영역에만 작게)
   - 안내 문구: '주민센터에 신고해도 SH 계약정보는 자동으로 바뀌지 않을 수 있습니다. SH에도 알려 주세요.' (공식 확인 전에는 '않을 수 있습니다' 표현 유지)
2. **아코디언 목록**: 개명 / 주민등록번호 변경 / 사망 / 혼인 / 이혼 (5행)

### 사유별 패널 내용

| 사유 | 패널 구성 |
|---|---|
| 개명 | 한 줄 요약 + 서류 5종 체크리스트(0/5) + 제출 방법 문의 안내 |
| 주민등록번호 변경 | 개명과 같은 서류 5종(동일 상수 공유) + 제출 방법 문의 안내 |
| 사망 | 공감·안내 문구 + 서류 3그룹(소제목 구분) + 센터 연락처 |
| 이혼 | 안내 문구 + 서류 3그룹(소제목 구분) + 센터 연락처 |
| 혼인 | 안내 문구 + 센터 연락처 (서류 목록은 확인 전까지 미표시) |

- 사망·이혼·혼인 패널에는 캐릭터, 장식, 축하 애니메이션을 쓰지 않는다.
- 서류 그룹은 접히는 항목이 아니라 소제목이다 (2단 아코디언 금지).

## 4. 아코디언 동작 사양

| 요구 | 구현 방식 |
|---|---|
| 0.4초 부드럽게 펼침/접힘 | 패널 `grid-template-rows: 0fr → 1fr`, `transition: 0.4s ease`. 내부 래퍼에 `overflow: hidden`, `min-height: 0` |
| + 아이콘 → × | 오른쪽 + 아이콘을 열릴 때 45도 회전 (0.4초, 패널과 같은 속도) |
| 한 번에 하나만 열림 | 열린 항목 id 상태 하나(`openId`). 다른 행을 누르면 이전 행 닫힘, 열린 행을 다시 누르면 `null` |
| Enter/Space 키 | 행 전체를 `<button>`으로 구현 |
| 줄 전체 클릭 | 버튼이 행 전체 너비를 차지 (아이콘만 클릭 구조 금지) |
| 큰 글씨 | 행 제목 21px 굵게, 본문 18px, 행 높이 64px 이상 |
| 접근성 | `aria-expanded`, `aria-controls`, 패널 `role="region"`, 포커스 윤곽선 유지 |
| 닫힌 패널 포커스 차단 | 닫힌 패널 안 요소가 Tab에 잡히지 않게 `inert` 또는 `visibility: hidden`. 단 `visibility`는 닫힘 전환이 끝난 0.4초 뒤에 적용해 애니메이션이 끊기지 않게 한다 |
| 동작 줄이기 | `prefers-reduced-motion`이면 전환 시간 0 |
| 자동 스크롤 보정 (선택) | 행을 열면 해당 행이 보이도록 스크롤. 불안정하면 삭제 가능한 선택 기능 |
| 체크 상태 | 행을 닫았다 열어도 화면 안 메모리에서 유지, 저장하지 않음 (새로고침 시 초기화) |

### 4-1. 큰글씨 모드 (돋보기 버튼)

| 항목 | 내용 |
|---|---|
| 위치 | 화면 오른쪽 위 고정. 스크롤해도 보이며 아코디언 행과 겹치지 않게 상단 영역에 배치 |
| 모양 | 돋보기 SVG 아이콘(28px 이상) + '큰글씨' 글자. 외부 이미지 파일은 쓰지 않음 |
| 상태 표시 | 켜지면 아이콘 안에 +가 보이고 글자가 '기본글씨'로 바뀌며 배경색이 달라짐 |
| 터치 영역 | 56px 이상 |
| 동작 | 누를 때마다 기본 ↔ 큰글씨 전환. `<button>`으로 구현해 Enter/Space 동작 |
| 접근성 | `aria-pressed`, 라벨 '큰글씨 모드 켜기/끄기' |
| 저장 | 저장하지 않음. 새로고침하면 기본 글씨로 복귀 |

**글자 크기 기준** (모든 크기를 `rem`으로 정의하고 최상위 글자 크기만 바꿔 한 번에 적용)

| 요소 | 기본 | 큰글씨 |
|---|---|---|
| 앱 제목 | 28px | 36px |
| 사유 행 제목 | 21px | 28px |
| 본문, 서류 목록 | 18px | 24px |
| 보조 문구, 배지 | 16px | 21px |
| 전화번호(펼침) | 28px | 36px |
| 행 높이 | 64px 이상 | 80px 이상 |
| 체크박스 | 24px | 32px |

- 큰글씨 모드에서도 가로 스크롤이 생기면 안 된다. 긴 서류명은 줄바꿈(`word-break: keep-all`, `overflow-wrap: anywhere`).
- + / × 아이콘, 체크박스, 배지도 함께 커진다. 돋보기 버튼 자체는 크기를 거의 키우지 않는다.
- 큰글씨 상태에서도 0.4초 펼침, 한 번에 하나만 열림 규칙은 그대로 동작한다. 패널 높이는 `grid-template-rows` 방식이라 자동으로 늘어난다.
- 글자 크기 전환 애니메이션은 생략 가능(아코디언 전환과 겹쳐 흔들릴 수 있음).

## 5. 구비서류 데이터

> 원칙: 서류명과 괄호 문구는 줄이거나 바꾸거나 추가하지 않는다. AI가 서류를 지어내지 않게 한다.

### 5-1. 개명 · 주민등록번호 변경 (동일 목록, 상수 1개 공유)

| 번호 | 서류명 | 수량 |
|---|---|---|
| 1 | 기본증명서 | 1부 |
| 2 | 주민등록초본 | 1부 |
| 3 | 인감증명서 | 1부 |
| 4 | 임대차계약서 | 원본 |
| 5 | 신분증 및 인감도장 | 지참 |

- 화면 제목: 개명 '개명으로 인한 명의변경 구비서류', 주민등록번호 변경 '주민등록번호 변경으로 인한 명의변경 구비서류'
- 한 줄 요약: '아래 서류를 준비해 SH에 제출해 주세요.'
- 제출 방법: '방문 전 담당 센터에 문의해 주세요'

### 5-2. 사망

- 상단 문구: '상심이 크시겠습니다. 담당자가 절차를 하나씩 안내해 드립니다.'
- 안내: '임차인(사망자) 서류는 사망처리가 완료되어 정리된 후 발급받으세요.'

**그룹A. 임차인(사망자) 서류 (각 1통)**
1. 기본증명서(상세)
2. 제적등본(폐쇄포함)
3. 혼인관계증명서(상세)
4. 가족관계증명서(상세)
5. 입양관계증명서(상세)
6. 친양자입양관계증명서(상세)
7. [임대주택]임대차계약서

**그룹B. 상속인(신청인) 서류**
1. 주민등록등본(세대주 변경)
2. 주민등록초본(주소이전내역포함)
3. 신분증
4. 인감증명서(본인발급분) 또는 본인서명사실확인서(해당용도발급분)
5. 인감도장 또는 서명(인감증명서에 날인된 도장 및 본인서명사실확인서의 서명은 신청서에 날인된 것과 일치해야 함)
6. 가족관계증명서(상세)
7. 입주자격증명서(해당세대만 – 수급자, 한부모 등) ← '해당되는 경우만' 배지

**그룹C. 상속인(동의인) 서류**
1. 인감증명서(본인발급분) 또는 본인서명사실확인서(해당용도발급분)
2. 인감도장 또는 서명(인감증명서에 날인된 도장 및 본인서명사실확인서의 서명은 신청서에 날인된 것과 일치해야 함)

- 그룹별 진행 표시: A 0/7, B 0/7, C 0/2
- 동의인 대상 해설(예: 상속인이 여러 명일 때)은 공식 확인 전까지 넣지 않는다.

### 5-3. 이혼 (SH 「이혼(혼인)으로 인한 임차권 양도 등 승인 신청서」 첨부서류 기준)

- 상단 문구: '명의변경은 상황에 따라 필요한 절차가 달라, 담당자가 직접 안내해 드립니다.'
- 안내: 'SH 「이혼(혼인)으로 인한 임차권 양도 등 승인 신청서」의 첨부서류 기준입니다.'

**그룹A. 임차인 서류 (각 1통, 1개월 이내 발급분)**
1. 혼인관계증명서
2. 가족관계증명서(상세)
3. 주민등록초본(임대주택이외 지역으로 전출)

**그룹B. 승계인 서류 (각 1통)**
1. 주민등록등본(세대주변경)
2. 가족관계증명서(상세)
3. 주민등록초본(최근 5년이내 주소변동사항 포함)

**그룹C. 공통 서류**
1. 임차권 등 양도각서(공증)
2. 임차인 및 승계인 인감증명서 각 1통(1개월이내 본인 발급분)
3. 임대차계약서 1통(분실시 분실신고서)
4. 임대료 및 관리비 최종월 납부영수증
5. 신분증 및 인감도장
6. 수급자 또는 한부모증명서 등(입주자격요건 갖추어야 하는 주택) ← '해당 주택만' 배지

- 그룹별 진행 표시: A 0/3, B 0/3, C 0/6
- '신청인(상속인)' 표현은 사망 양식과 공용이라 남은 문구이므로 화면에서는 쓰지 않는다.
- 이혼 판결문 또는 조정조서는 신청서 첨부서류에 없으므로 화면에 넣지 않는다 (7장 확인 항목).

### 5-4. 혼인
- 서류 목록 미확정. 패널에 '혼인에 따른 명의변경은 담당자가 직접 안내해 드립니다.' 문구와 센터 연락처만 표시한다.
- 위 신청서 제목에 '이혼(혼인)'이 함께 있으므로, 같은 양식을 쓰는 것이 확인되면 5-3 그룹을 재사용한다.

### 동작
1. '거주하시는 구를 선택해 주세요' 버튼 5개 + '그 외 지역'
2. 구 선택 시 센터 이름과 표시 주소 표시, 큰 버튼 2개

   - **지도 보기**: `https://map.naver.com/p/search/` + 지도 검색어(URL 인코딩), 새 탭(`target="_blank"`, `rel="noopener noreferrer"`)

### 1차: 골격 + 개명·주민등록번호 변경
```

[상단] 제목 '바뀐 내 정보, SH에도 알려주세요!', 부제 '해당하는 상황을 눌러 구비서류를 확인하세요', 안내 문구 '주민센터에 신고해도 SH 계약정보는 자동으로 바뀌지 않을 수 있습니다. SH에도 알려 주세요.', 첨부한 청렴 캐릭터 이미지를 작게 사용.

- 한 번에 하나만 열린다. 열린 항목 id 상태 하나로 관리, 열린 행을 다시 누르면 닫힌다.
- 행 제목 21px 굵게, 본문 18px, 행 높이 64px 이상.

[개명, 주민등록번호 변경 패널] 같은 서류 상수 하나를 공유한다.

 안내: '제출 방법은 방문 전 담당 센터에 문의해 주세요'

[큰글씨 모드]
- 화면 오른쪽 위에 고정 버튼을 둔다. 돋보기 SVG 아이콘(28px 이상)과 '큰글씨' 글자를 함께 표시하고, 터치 영역은 56px 이상으로 한다. 외부 이미지 파일은 쓰지 않는다.
```
